This repository features a stand-alone Python script for
a specific spatial analysis. I tested this script on a 
Windows 10 laptop. Before running the script, please 
complete these steps:

- Install the latest version of Microsoft Visual C++ at
https://visualstudio.microsoft.com/visual-cpp-build-tools

- Install several Python libraries with
```
pip install pygeoda
``` 

- Learn about pygeoda at 
https://github.com/GeoDaCenter/pygeoda
